Mes objectifs

Yazio → Apple Santé

  1. Dans Yazio : Profil → Réglages → Comptes et appareils connectés → Apple Santé.
  2. Autorise l'écriture de l'énergie alimentaire, des protéines, glucides et lipides. Autorise aussi la lecture du poids si tu te pèses ailleurs.
  3. Vérifie dans Santé → Parcourir → Nutrition que les repas du jour apparaissent.

Raccourci iPhone du soir

Dans l'app Raccourcis, crée un raccourci nommé « Bilan Santé » avec ces actions, dans l'ordre :

  1. Rechercher des échantillons de santé : Type = Poids, trier par Date de début (le plus récent d'abord), limite 1.
  2. Rechercher des échantillons de santé : Type = Nombre de pas, Date de début = Aujourd'hui. Puis Calculer des statistiques → Somme.
  3. Même chose (recherche aujourd'hui + Somme) pour Énergie alimentaire, Protéines, Glucides et Lipides.
  4. Action Texte, en insérant chaque résultat comme variable : 
    SANTE;date=[Date actuelle];poids=[Poids];pas=[Somme pas];kcal=[Somme énergie];prot=[Somme protéines];gluc=[Somme glucides];lip=[Somme lipides]
  5. Copier dans le presse-papiers.
  6. Ouvrir les URL : l'adresse de cette page suivie de #aujourdhui.

Puis Raccourcis → Automatisation → Heure de la journée (par ex. 21 h 30) → Exécuter immédiatement → « Bilan Santé ». Chaque soir, l'appli s'ouvre : appuie dans la case d'import, Coller, Enregistrer.

Les unités (« 78,4 kg ») et les virgules sont reconnues automatiquement.

Jow

Jow ne partage pas ses données : ajoute tes recettes dans l'onglet Repas (nom + lien). La recette du jour s'affiche dans Aujourd'hui.

Installer l'appli

iPhone : ouvre cette page dans Safari, Partager → « Sur l'écran d'accueil ».
PC : dans Chrome ou Edge, menu ⋮ → « Installer la page en tant qu'application » (ou « Créer un raccourci… »).

Tes données sont enregistrées dans ton compte Claude : reste connecté sur les deux appareils pour les retrouver.
