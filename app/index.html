Pour synchroniser l'iPhone et le PC, renseigne l'URL et la clé publique de ton projet Supabase dans config.js (voir le README).

Mes objectifs

Yazio → Apple Santé

  1. Dans Yazio : Profil → Réglages → Comptes et appareils connectés → Apple Santé.
  2. Autorise l'écriture de l'énergie alimentaire, des protéines, glucides et lipides. Autorise aussi la lecture du poids si tu te pèses ailleurs.
  3. Vérifie dans Santé → Parcourir → Nutrition que les repas du jour apparaissent.

Raccourci iPhone du soir

Connecte-toi d'abord à ton compte : le raccourci envoie tes données directement dans ton espace.

1. Ton adresse d'envoi

2. Ton jeton secret

Le jeton ne s'affiche qu'une fois. Garde-le uniquement dans le raccourci. En cas de doute, crée-en un nouveau : l'ancien cesse aussitôt de fonctionner.

3. Le raccourci : dans l'app Raccourcis, crée « Bilan Santé » avec ces actions, dans l'ordre :

  1. Rechercher des échantillons de santé : Type = Poids, trier par Date de début (le plus récent d'abord), limite 1.
  2. Rechercher des échantillons de santé : Type = Nombre de pas, Date de début = Aujourd'hui. Puis Calculer des statistiques → Somme.
  3. Même chose (recherche aujourd'hui + Somme) pour Énergie alimentaire, Protéines, Glucides et Lipides.
  4. Obtenir le contenu de l'URL : colle l'adresse ci-dessus. Touche « Afficher plus » :
    • Méthode : POST
    • En-têtes : ajoute X-Jeton avec ton jeton comme valeur
    • Corps de la requête : JSON, avec ces champs (type Texte), en insérant chaque résultat comme variable : 
      date  → Date actuelle
poids → Poids
pas   → Somme des pas
kcal  → Somme énergie
prot  → Somme protéines
gluc  → Somme glucides
lip   → Somme lipides
  5. Afficher la notification avec le « Contenu de l'URL » : tu verras « Données du … enregistrées ».

Puis Raccourcis → Automatisation → Heure de la journée (par ex. 21 h 30) → Exécuter immédiatement → « Bilan Santé ». Plus rien à coller : les données arrivent toutes seules.

Les unités (« 78,4 kg ») et les virgules sont reconnues. Tu peux relancer le raccourci plusieurs fois par jour : la dernière valeur remplace la précédente.

Jow

Jow ne partage pas ses données : ajoute tes recettes dans l'onglet Repas (nom + lien). La recette du jour s'affiche dans Aujourd'hui.

Installer l'appli

L'appli est installée sur cet appareil.

iPhone : ouvre cette page dans Safari, Partager → « Sur l'écran d'accueil ».
PC : dans Chrome ou Edge, l'icône d'installation dans la barre d'adresse, ou menu ⋮ → « Installer Mon régime ».
